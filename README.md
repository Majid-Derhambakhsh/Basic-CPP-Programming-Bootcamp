## Guide

#### This course can be used as follows:

#### 1. Clone repository

```bash
git clone https://github.com/Majid-Derhambakhsh/Basic-CPP-Programming-Bootcamp
```

#### 2. Open repository folder

```bash
cd Basic C++ Programming Bootcamp
```

#### 3. Read the course document

```text
Basic C++ Programming Bootcamp.pdf
```

#### 4. Study examples and solve exercises

```text
- Read concepts
- Run examples
- Modify source code
- Complete exercises
```
